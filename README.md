# 🧪 Sample Katalon Automation Framework (Web + Mobile)

This project is a sample test automation framework built using **Katalon Studio**. It showcases real-world web and Android test automation skills, including data-driven testing, reusable keywords, and reporting. Designed for portfolio and demonstration purposes.

---

## 🔧 Tech Stack

- **Katalon Studio** (Web + Mobile support)
- **Appium** (for Android automation)
- **Groovy** (for custom keywords)
- **Test Data**: Excel (Data-driven tests)
- **HTML Reports** (Katalon built-in)

---

## ✅ Features Covered

### 🔐 Login Functionality
- Valid login with correct credentials
- Invalid login with error message verification (Web + Android)

### 🛒 Add to Cart
- Add one or more products to cart
- Cart icon reflects correct item count

### 📄 Data-Driven Testing
- Read input values (e.g. usernames, products) from Excel file
- Verify UI elements match expected data

### 🧱 Reusable Custom Keywords
- Built Groovy-based keywords to simplify test logic
- Examples: `verifyAllExcelItemsExistInUI`, `verifyText`, etc.

### 📑 HTML Reports
- Attached sample reports for:
  - Web test run (`Reports/WebSanity.html`)
  - Mobile test run (`Reports/AndroidSanity.html`)
---

## 🚀 How to Run

1. Open the project in **Katalon Studio**
2. Configure device (Android Emulator or real device) if running mobile tests
3. Open a test case or test suite
4. Click **Run**

✅ Make sure Excel file paths and test object locators are correctly configured.
